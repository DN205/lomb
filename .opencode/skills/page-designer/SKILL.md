# Page Designer

Lomb is a Zola 0.23 static site. Every page is Markdown plus a template that
supplies the header, side panels and navigation. Your job is to fill the content
correctly and leave the rendered UI to the template.

## 1. Pick the page type

| Page | Content path | Template | Read |
| --- | --- | --- | --- |
| Species sheet | `content/species/<english-kebab>.md` | `tree-page.html` | `page-types/species-page.md` |
| Taxonomy explainer | `content/taxonomy/{linnea,cladistics}.md` | `taxonomy-page.html` | `page-types/taxonomy-page.md` |
| Taxonomy rank | `content/taxonomy/{kingdom,phylum,class,order,family,genus,species}.md` | `taxonomy-page.html` | `page-types/taxonomy-page.md` |
| Taxonomy group | `content/taxonomy/groups/<latin>.md` | `taxonomy-group.html` | `page-types/taxonomy-page.md` |
| Standalone page | `content/{about,privacy}.md` | `page.html` | `page-types/basic-page.md` |
| Glossary | `content/glossary.md` | `glossary.html` | `page-types/basic-page.md` |
| Sources | `content/sources/_index.md`, `references.md` | `sources.html`, `sources-page.html` | `page-types/basic-page.md` |
| Catalogue | `content/species-index.md` | `species-index.html` + `species-list.html` | `page-types/basic-page.md` |

Read the page-type file first. Read `style.md` only when the change touches
markup, a panel, a listing row, spacing or CSS.

## 2. Work in this order

1. Read an existing page of the same type and copy its shape — the neighbours
   are the style guide.
2. Write the front matter (TOML between `+++`, never YAML).
3. Write the body: `##` sections in the order the page type prescribes.
4. Run `zola check`. Fix every link and anchor warning before finishing.
5. Use `zola serve` (http://127.0.0.1:1111) to look at it if layout matters.

## 3. Rules that apply to every page

- **Visible copy is Hungarian; identifiers are English.** Filenames, front-matter
  keys, CSS classes, ids and JS stay English. `verified_by` values stay
  `"Human"` / `"AI"`.
- **Never render your own `h1`.** The template prints `page.title` in the
  `.page-header`. Start the body with a paragraph (species, rank pages) or a
  `##` heading (explainers).
- **`description` is the lead paragraph**, so write a full sentence, not a
  fragment.
- **Typography:** en-dash ranges (`25–40 m`), Hungarian quotes (`„…”`), `·`
  between metadata items, SI units, no marketing tone and no first person.
- **Internal links** use `@/path.md` (`[makk](@/glossary.md#makk)`). Put external
  links on the Hivatkozások page instead of scattering them in articles.
- **Glossary terms are linked, not redefined.** Link the first occurrence of a
  term in the article to its anchor and let the glossary carry the definition.
- **`verified_by = "AI"` by default.** Set `"Human"` only after a real factual
  review of taxonomy, measurements, distribution and wording. Never fake it.
- **Deep links deserve ids.** Give article headings an explicit id only when
  something links to them (`## Megjelenése {#appearance}`); otherwise leave
  Zola's default anchor.
- **Never edit `public/`.** It is build output, regenerated by `zola build`.

## 4. Template gotchas (Tera 2 in Zola 0.23)

- Macros and `{% import %}` no longer exist. Shared markup is a component:
  `{% component species.list(pages) %}…{% endcomponent %}`, called as
  `{{<species.list pages={section.pages} />}}`. Non-string arguments need `{…}`.
- Templates guard optional taxonomy with `is defined`, so a page missing
  `[extra.linnaean]` or `[extra.cladistic]` still builds and silently loses the
  Rendszertan block. Missing front matter is therefore a silent failure — always
  diff against a neighbouring page.
- Species pages are rendered through the section's `page_template`; you do not
  set `template` on them.
- Listing rows need their `data-search` attribute kept in sync with the front
  matter, otherwise the filter cannot find the page.

## 5. Files that matter

| Path | Role |
| --- | --- |
| `templates/base.html` | Shell: skip link, main, home button, footer |
| `templates/tree-page.html` | Three-column species sheet |
| `templates/taxonomy-page.html` | Two-column explainer / rank layout |
| `templates/taxonomy-group.html` | Group page with breadcrumb and species list |
| `templates/taxonomy.html`, `groups-index.html` | Taxonomy section and group index |
| `templates/page.html`, `glossary.html`, `sources*.html` | Standalone layouts |
| `templates/species-index.html`, `species-list.html` | Catalogue and its filter component |
| `static/css/tree.css` | The only stylesheet (`compile_sass = false`) |
| `static/js/filter.js`, `taxonomy-filter.js` | Accent-insensitive list filters |
| `content/species/_index.md` | Section config: `page_template`, `sort_by = "title"`, `render = false` |
| `content/taxonomy/_index.md`, `groups/_index.md` | Taxonomy section configs |

## 6. Done means

- `zola check` passes with no broken links or anchors.
- Front matter is complete and internally consistent.
- The page appears at the expected URL in `zola serve`.
- Only files related to this page changed.
